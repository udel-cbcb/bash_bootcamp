# Bash Commands & Vocabulary Reference Sheet

This quick reference covers the essential Bash commands and concepts from this tutorial. While not an exhaustive manual, mastering these core tools gives you everything you need to perform virtually any data analysis workflow on the command line.

## Commands

**bash** - executes a specified bash script

**cd** - changes directory

**chmod** - changes the permissions of a file

**cp** - copies a file or directory

**echo** - outputs strings that are passed to it as arguments

**grep** - searches a file for a given pattern of characters

**head** - prints the first lines of a given file (default no. of lines is 10)

**less** - displays the contents of a file in a separate screen (use q to exit)

**ls** - lists the contents of a directory

**man** - displays the manual page for the given command (may need to be [installed](https://unix.stackexchange.com/questions/585521/missing-man-pages-under-debian-wsl)).  Alternatively, see the [online manual](https://www.man7.org/linux/man-pages/man1/bash.1.html).

**mkdir**- makes a new directory

**nano** - a popular command line text editor

**od -c** - displays all characters in a file (including whitespace)

**pwd** - prints the full working directory path to the screen

**rm** - removes (deletes) files and directories

**sed** - a stream editor that modifies lines from a file

**tail** - prints the last lines of a given file (default no. of lines is 10)

**touch** - modifies the timestamp on a file

**wget** - retrieves content/files from a web server

## Vocabulary

**Bash** - Unix shell and command language, open source replacement for the Bourne shell

**Command** - a specific instruction provided to a computer

**ommand Line** - a text interface with your computer, provided by a terminal

**Directory** - contains a collection of files and sometimes other directories, mapped to a physical location on a computer's hard drive

- Working Directory - the directory where a user or running program is currently located
- Home Directory - the directory that contains files and directories for a specific user

**Error** - an issue that arises unexpectedly and results in unexpected behavior by the computer

**File** - an object that stores information of some kind
Tab-separated File - text-based format for storing tabular data in which data fields are separated by tab characters (\t)

**Flag** - a common way to specify options for a command, generally preceded by - or --

**Kernel** - a computer program at the heart of an operating systems that interfaces directly with the hardware

**Path** - the location of a file, directory, software, etc. on a computer

- Relative Path - the location of a file or directory with respect to the working directory (the directory that the user is currently in)
- Absolute Path - the location of an item with respect to the home directory

**Operating System (OS)** - the system software that manages all other software/programs on a computer

**Standard Error (stderr)** - the place where error messages go (usually your screen, by default)

**Standard In (stdin)** - the input stream for a command

**Standard Out (stdout)** - where many commands print their output (directly to the screen)

**Shell** - an interface between a user and the kernel that allows the user to access the operating system

**Terminal** - a text-based interface that allows you to interact with the computer via a shell

**Variable** - an object that stores data of some kind
